# Refactoring Plan for shopping.js

## Current State
- shopping.js: 1050 lines - too large, mixed concerns
- Existing modules: menu.js (563), journal.js (282), util.js (118), drag.js (453), photo.js (169), add-item.js (210)
- grand total of 2845 lines in *.js

## Goal
Break shopping.js into focused, single-responsibility modules while maintaining compatibility with existing code.

================================================================================
## Phase 1: Create state.js (~100 lines)
================================================================================

### Purpose
Centralize all global state variables and state-related UI functions.

### Extract from shopping.js:
- Line 8-14: State variables
  - allLists
  - currentList
  - currentListLastModified
  - saveTimeout
  - focusItem
  - isSaving
  - isModified

- Line 74-97: State management functions
  - updateStatus() - update save/modified indicator
  - setBanner(message, type) - show error/info banner
  - clearBanner() - hide banner

### Create window.State API:
```javascript
window.State = {
  // Getters
  getAllLists: () => allLists,
  getCurrentList: () => currentList,
  getCurrentListLastModified: () => currentListLastModified,
  getFocusItem: () => focusItem,
  isSaving: () => isSaving,
  isModified: () => isModified,
  
  // Setters
  setAllLists: (lists) => { allLists = lists; },
  setCurrentList: (list) => { currentList = list; },
  setCurrentListLastModified: (lm) => { currentListLastModified = lm; },
  setFocusItem: (item) => { focusItem = item; },
  setIsSaving: (val) => { isSaving = val; updateStatus(); },
  setIsModified: (val) => { isModified = val; updateStatus(); },
  
  // Status/Banner functions
  updateStatus,
  setBanner,
  clearBanner
};
```

### Dependencies
- None (pure state management)

### HTML Script Tag
Add to index.cgi before shopping.js:
```html
<script src="state.js"></script>
```

4. Test - everything should still work

2. Update index.cgi to include storage.js

4. Test - save/load should still work

### Step 3: Expand util.js

2. Update shopping.js to use Util.focusEditable() etc
3. Test - rendering and utilities should work

### Step 4: Create list-operations.js
1. Create list-operations.js with list operations
2. Update index.cgi to include list-operations.js
3. Update shopping.js to use ListOps API
4. Update menu.js callbacks to use ListOps
5. Test - all list operations should work

### Step 5: Create rendering.js
1. Create rendering.js with all rendering code
2. Update index.cgi to include rendering.js
3. Update shopping.js to use Rendering API
4. Test - rendering should work perfectly

### Step 6: Slim shopping.js
1. Remove all extracted code from shopping.js
2. Update window.ShoppingApp to delegate to modules
3. Clean up and organize remaining init code
4. Test - entire app should work

### Step 7: Final verification
1. Test all features: create, edit, delete lists

3. Test drag & drop

5. Test photo capture
